# Checkpoint - BinanceAgent - 2026-06-27

## Resumen
Se avanzo el bot hacia operacion autonoma: seleccion automatica de activos, gestion de riesgo por posicion, kill-switch global, trailing adaptativo por volatilidad y backtest reproducible offline del scanner. La app quedo validada con compilacion backend, pruebas directas y build frontend.

## Cambios realizados
- Se agrego `backend/risk.py` con sizing automatico, guardas de perdida diaria, racha de perdidas, cooldown y kill-switch por drawdown global.
- Se agrego `backend/scanner.py` con watchlist normalizada, scoring de candidatos y regla de rotacion de simbolo.
- `backend/bot_logic.py` ahora bloquea compras por condiciones de riesgo, calcula tamano por riesgo, rota activos cuando no hay posicion abierta, persiste estado de scanner y aplica kill-switch global.
- `backend/strategies/base_strategy.py` ahora ajusta el trailing por ATR cuando `adaptive_trailing_enabled` esta activo.
- `frontend/src/components/SettingsPanel.jsx` expone scanner autonomo, risk engine, kill-switch y trailing adaptativo.
- `frontend/src/App.jsx` incorpora defaults para scanner, kill-switch y trailing adaptativo.
- Se agrego `backend/backtest.py` para backtesting offline del scanner sobre dataframes OHLCV.
- `backend/__init__.py` fuerza salida UTF-8 para evitar errores `charmap` en Windows.
- Se agregaron pruebas directas para riesgo, scanner, backtest y salidas adaptativas.

## Estado actual
Funciona la compilacion Python, los scripts de prueba existentes, el backtest offline y el build de Vite. El bot mantiene el flujo original de credenciales por login/register y no depende del `.env` para Binance.

La rotacion automatica cambia de activo solo si no hay posicion abierta. El kill-switch desactiva compras, detiene el bot y vende la posicion actual si el drawdown global supera el umbral configurado.
